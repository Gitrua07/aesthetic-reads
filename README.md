# aesthetic-reads

## Overview

Create a program where it allows users to collect a group of images and assigns those images to 1+ book(s). These images should fit the “vibe” of the assigned book. The user interface will be modelled like pinterest. There will be a search bar for books which is linked to a book API. As well, there is an option to add those books manually. Images must be saved from external sources (e.g Unsplash) which the user will need to search on the internet. The mood boards are titled based on the vibe they resemble, for example these vibes can be Dark Academia, Soft Cottagecore, Melancholic Winter, or Surreal Art-Inspired Reads.
